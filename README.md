## The joke

> I put 'per my last email' in my will so my family knows I already answered that question.

The setup sounds like an ordinary office phrase, then the punchline moves it
somewhere nobody expects — a last will — turning the most passive-aggressive
email line in office life into a final legal instruction.

## How it works

`main.ts` writes the single-line joke (89 characters) to `/output/entry.txt`
when run with Node:

```sh
node main.ts
```
